# Google Two Column

Userscript for Google web search on wide screens (≥1024px):

- Results in two columns as cards
- AI Overview hidden
- Knowledge panel first in the left column
- More results load automatically as you scroll

## Install

With [Tampermonkey](https://www.tampermonkey.net/) installed, open:

https://raw.githubusercontent.com/uhovohu/google-two-column/main/google-two-column.user.js

Updates are picked up automatically.
